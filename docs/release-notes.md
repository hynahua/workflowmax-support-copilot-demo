# Public release preparation

This is a fresh source snapshot with a new, neutral Git history. The original development repository, commit identities, working documents and runtime evidence are not part of the release.

Application logic, tests, prompts, contracts and synthetic training data are included. The public copy retains the demonstration URL in the README, replaces internal authorization identifiers with neutral demonstration identifiers, and makes the packaging script independent of an existing Site projectID. Local navigation opens local practice instead of an external operator deployment. Diagram source paths use the included diagrams directory. These release-only adaptations do not change the currently hosted application.

The colorful memory map and the Workflow diagram use the reviewed steps and branches. The Workflow page displays the editable Mermaid layout, and its PDF and SVG show the fixed single-page layout. No screenshot of a saved live conversation is included. Source metadata and test email fixtures use reserved example domains, not personal contacts.

The existing GitHub account name and demo website address are intentionally public. Source files and commit metadata still exclude real personal contact details, credentials, private preparation records and the original development history. The live demo retains its own authenticated owner gate; public source access is not paid API authorization.

Optional Python diagram rendering requires Pillow/ReportLab and appropriate fonts; those scripts are not required to run or test the application. Pre-rendered diagram assets are included for direct reading.
