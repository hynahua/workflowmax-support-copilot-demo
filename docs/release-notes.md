# Public release preparation

This is a fresh source snapshot with a new, neutral Git history. The original development repository, commit identities, working documents and runtime evidence are not part of the release.

Application logic, tests, prompts, contracts and synthetic training data are included. The public copy removes personal deployment URLs, replaces internal authorization identifiers with neutral demonstration identifiers, and makes the packaging script independent of an existing Site projectID. Local navigation opens local practice instead of an external operator deployment. Diagram source paths use the included diagrams directory. These release-only adaptations do not change the currently hosted application.

The approved colorful memory map and precise English PNG/SVG/Mermaid diagram are copied without changing their information. No screenshot of a saved live conversation is included. Source metadata and test email fixtures use reserved example domains, not personal contacts.

No public repository or personal website link is configured in this snapshot. Publication requires a neutral publishing identity and neutral destination. A public GitHub owner/profile or push actor can identify its account independently of file contents; neutral commit metadata alone is insufficient to anonymize a personal account.

Optional Python diagram rendering requires Pillow/ReportLab and appropriate fonts; those scripts are not required to run or test the application. Pre-rendered diagram assets are included for direct reading.
